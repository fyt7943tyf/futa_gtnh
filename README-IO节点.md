# 共享 IO 节点

共享背包存储的**专用自动化输入输出口**。共享终端方块功能繁多（查看库存、合成、面配置都挤在一起），这个方块只做一件事：按面的配置，在「相邻容器」和「共享存储」之间主动搬运物品与流体。不带查看库存的界面，也不能被管道当作容器抽取（没有被动路径）。

## 外观与连接（参考 EnderIO 导管）

方块**不占满整格**：中心是一个 6×6×6 像素的小节点，只有「那一面真的挨着能搬东西的方块」时才向该面伸出一根连接臂，臂端有一块贴在格子边缘的端帽。放置时默认六面全部关闭，模型上只有灰色连接。

连接判定比「邻居是个容器」更严：

- 物品：邻居实现 `IInventory`，且（对有面概念的 `ISidedInventory`）在它对着节点的那个面上**真的开出了可访问槽位**——被覆盖板封死的面、贴着石头都不会伸臂；
- 流体：邻居实现 `IFluidHandler` 且该面报得出罐子信息；
- 共享终端和其他 IO 节点永远不算连接目标（从共享存储往共享存储搬没有意义）。

连接在放置、邻居方块变化时立即重算，另有每 5 秒一次的低频兜底（覆盖板更换、机器切换朝向这类「方块没换但能力变了」的情况）。

## 交互

- **右键某根连接臂**：打开那一面的配置界面（点哪根臂配哪个面，EnderIO 的做法）；点到中心节点时打开第一个有连接的面。
- **潜行右键**：让路给 GT 扳手，正常拆卸。
- 界面里也可用 ←/→ 在有连接的面之间切换。

## 配置界面（三个页签）

- **面配置**：物品、流体各一组方向按钮，四态循环——**关 / 抽入 / 输出 / 输入输出**。抽入＝邻居→仓库，输出＝仓库→邻居。默认全部关。同一面的物品和流体方向互相独立。
- **输出筛选**：这一面的输出白名单，与共享终端的筛选页同一套（条目 + 矿辞预设 + 自定义矿辞前缀，任意命中即通过，空白名单＝禁止输出）。区别是 IO 节点这边**默认按数量倒序**排列共享存储条目（可切名称/模组）。抽入不经过筛选。
- **节奏**：这台节点自己的间隔（每 N tick 一轮）与每轮数量上限（物品/流体），与共享终端同一组档位。

端帽颜色就是当前模式的世界内可视化：**灰＝关、绿＝抽入、橙＝输出、黄＝双向**；物品和流体接在同一面时端帽对半分，两半各按各的颜色显示。

## 搬运引擎与守恒

主动搬运完全复用共享终端的 `TerminalIoEngine`：先模拟能搬多少、真搬、搬不进去的部分原样退回，不允许「扣了没送到」或「送了没扣」。相邻方块只认 Forge 的 `IInventory` / `IFluidHandler`（箱子、GT 机器、储罐都支持），搬运异常只跳过当轮，不会带崩服务端 tick。

## 合成

末影珍珠×2 + 铁锭×4 + 漏斗×1（十字形，漏斗居中），比共享终端便宜。`enableRecipe=false` 时与其它配方一起关闭。

## 技术说明

- 网络包：`PacketIoNodeSync`（S2C，#29，配置快照+连接掩码+邻居名）、`PacketIoNodeConfig`（C2S，#30，整份上行/权威值请求）。服务端校验：必须开着节点界面、距离 8 格内、数字一律吸附回合法档位（客户端发来的值不作数）。
- 渲染状态（连接掩码+每面模式）通过方块实体描述包同步，`markBlockForUpdate` 驱动刷新；碰撞与点选逐组件进行（中心核 + 每根臂 + 端帽），悬停描边只框住视线命中的组件。
- 模式枚举在 `TerminalIoConfig.Mode` 末尾追加了 `PUSH_PULL`（ordinal 3），旧存档按 ordinal 读写不受影响；共享终端自己的界面仍只在关/抽入/输出三态间切换。
