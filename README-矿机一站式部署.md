# 矿机一站式部署（采矿场 / 油气钻机）

> 三个部件：**矿机一站式部署器**（物品）+ **免料自动维护仓**（GT 仓体）+ **AE 采矿枢纽覆盖板**（GT 覆盖板）。
> 目标：采矿场/油气钻机搬家时，右键一下 = 整个多方块成型 + IO 全自动接 AE，玩家只剩能源仓要自己接。

## 使用流程

1. 放置采矿场/油气钻机的**主控制器**（朝向决定整个结构的方向）。
2. 手持**矿机一站式部署器**右键控制器：
   - 外壳 + 框架 + 全部仓体（输入仓/输入总线/输出总线或输出仓/免料自动维护仓/能源仓）一次成型；
   - 材料按 **背包 → 共享背包 → 随身 ME 终端** 三级扣取（与反应堆部署器同一套口径，全是无 NBT 全新件的精确匹配）；
   - 摆完自动把**AE 采矿枢纽覆盖板**贴到控制器上（背包/共享背包/AE 里有覆盖板物品才贴）；
   - **潜行右键 = 只看材料清单**（需求 ×数量 + 已就位/被挡统计），不动方块。
3. 接能源仓（档位不够/没有会留外壳位，自己替换即可），接电。
4. AE 侧保持一台在线的**发信器**（就是 AE 无线控制那个发信器方块，放在你的 ME 网络里）。

覆盖板首次运行时如果机器所有者同队伍的发信器**恰好只有一台**会自动绑定；多台时潜行空手右键控制器上的覆盖板选一台。

搬家 = 拆掉旧的 → 新位置放控制器 → 再右键一次。

## 语义细节

### 结构与仓位

形状与 GT5u `MTEDrillerBase` 的结构定义一致（3×7×3，钻井竖井在控制器背面），部署器只往
空气/可替换方块里放、被实体占着的格子跳过。仓位分配：

| 仓位 | 采矿场 | 油气钻机 |
|---|---|---|
| 竖井旁 | 输入总线（采矿管道） | 输入总线（采矿管道） |
| 竖井旁 | 输入仓（钻井液） | 输出仓（油气） |
| 竖井旁 | 输出总线 ×1 | 免料自动维护仓 |
| 后排 | 输出总线 ×2 | 能源仓 |
| 后排 | 免料自动维护仓 / 能源仓 | 补外壳 |

- 某种仓的**原型找不到**（如维护仓功能关了）→ 该位补外壳，聊天栏说明；
- 某种仓的**物品没凑够** → 缺的格子留外壳，聊天栏报缺口；
- **升级路径**：结构已建好（仓位上是外壳）时再点一次部署器，会把外壳收回（退回共享背包）换成仓体——先建结构后补仓体是合法流程；
- 被其它方块占住的格子不动，报告"被挡"。

仓体放置走 GT `ItemMachines` 同款管线（大 MTE ID 存在方块实体里），所有者记为部署玩家。

### 免料自动维护仓

GT 自动维护仓的免耗材版：每次修复**不消耗任何材料**直接修满六个工具位。判定继承自
`MTEHatchMaintenance`（instanceof），所以**一切收维护仓的多方块都能用它**，不限于钻机。
MTE ID 默认 32702（`minerAutoMaintenanceMetaTileId`，冲突时改配置）。

### AE 采矿枢纽覆盖板

只能贴在采矿场/油气钻机的**主控制器**上（正面除外，整机限一个），通过 AE 无线发信器定位
ME 网络（跨维度可、零线缆），每 20 tick（可配）搬一轮：

- **补给**：采矿场 → 钻井液补进输入仓（目标量 `minerIoFluidBuffer`，默认 8000 mB，单轮 ≤4000 mB）；
  采矿管道补进输入总线（`minerIoPipeBuffer`，默认 64）；油气钻机 → 只补管道。
- **回收**：输出总线（矿物）与输出仓（油气）的内容泵回 ME 网络，单轮 ≤128 件 / ≤4000 mB；
- 每次搬运从发信器所在网络的能源缓存**扣 AE 电**（与 AE2 导入/导出总线同一套 `poweredInsert/poweredExtraction`
  功耗模型），网络没电就安静待机；
- 发信器离线/冲突/不同队伍时安静待机，GUI 与 tooltip 显示链路状态。

产线闭环示例：输出总线里的矿物进 ME → 合成 CPU 补货 → 管道/钻井液从 ME 出 → 机器不停机。

### 配置项（futa_gtnh.cfg）

| 项 | 默认 | 说明 |
|---|---|---|
| `enableMinerDeployer` | true | 注册部署器 + 覆盖板 |
| `enableMinerAutoMaintenance` | true | 注册免料自动维护仓 |
| `minerAutoMaintenanceMetaTileId` | 32702 | 维护仓 MTE ID（冲突时改） |
| `minerIoFluidBuffer` | 8000 | 钻井液补货目标量（mB） |
| `minerIoPipeBuffer` | 64 | 采矿管道补货目标量（个） |
| `minerIoCoverInterval` | 20 | 覆盖板搬运间隔（tick） |

### 配方

- 部署器：钢板×4 + 胶带 + 末影珍珠×2 + 基础电路 + 钢螺丝；
- AE 采矿枢纽覆盖板：末影珍珠 + 红石 + 铁板；
- 免料自动维护仓：钢板 + 胶带 + 钢螺丝 + MV 机器壳。

## 明确不做

- 不新建多方块、不改 GT5u 代码；
- 不用 ME 仓体（输入/输出仍走普通仓 + 覆盖板搬运），玩家想用 GT 原生 ME 仓自己换也完全兼容；
- 不自动接能源（GT 能源接线习惯各服务器不同，留给玩家）。

## 已知边界

- 结构区被地形/其它方块占用时该格跳过（报告"被挡"），不会破坏玩家的东西；
- 覆盖板搬运的网络记账与 AE2 原生总线一致，中途断电最多丢一轮的搬运量；
- 部署器不做撤销——拆掉的方块用扳手/镐正常回收。
