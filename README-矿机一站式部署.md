# 矿机一站式部署（采矿场 / 油气钻机）

> 两个配套物品：**矿机一站式部署器** + **AE 采矿枢纽覆盖板**。结构使用普通 GT 维护仓。
> 目标：采矿场/油气钻机搬家时，右键一下 = 整个多方块成型 + IO 全自动接 AE，接电与维护按 GT 原版流程处理。

## 使用流程

1. 放置采矿场/油气钻机的**主控制器**（朝向决定整个结构的方向）。
2. 手持**矿机一站式部署器**右键控制器：
   - 备齐材料即可摆好外壳、框架和仓体（输入仓/输入总线/输出总线或输出仓/普通 GT 维护仓/能源仓）；
   - 材料按 **背包 → 共享背包 → 随身 ME 终端** 三级扣取（与反应堆部署器同一套口径，全是无 NBT 全新件的精确匹配）；
   - 摆完自动把**AE 采矿枢纽覆盖板**贴到控制器上（背包/共享背包/AE 里有覆盖板物品才贴）；
   - **潜行右键 = 只看材料清单**（需求 ×数量 + 已就位/被挡统计），不动方块。
3. 接能源仓（档位不够/没有会留外壳位，自己替换即可），接电。
4. AE 侧保持一台在线的**发信器**（就是 AE 无线控制那个发信器方块，放在你的 ME 网络里）。

覆盖板首次运行时如果机器所有者同队伍的发信器**恰好只有一台**会自动绑定；多台时潜行空手右键控制器上的覆盖板选一台。

搬家 = 拆掉旧的 → 新位置放控制器 → 再右键一次。

## 语义细节

### 结构与仓位

形状与 GT5u `MTEDrillerBase` 的结构定义一致（3×7×3，钻井竖井在控制器背面），部署器只往
空气/可替换方块里放、被实体占着的格子跳过。仓位分配：

| 仓位 | 采矿场 | 油气钻机 |
|---|---|---|
| 竖井旁 | 输入总线（采矿管道） | 输入总线（采矿管道） |
| 竖井旁 | 输入仓（钻井液） | 输出仓（油气） |
| 竖井旁 | 输出总线 ×1 | 普通 GT 维护仓 |
| 后排 | 输出总线 ×2 | 能源仓 |
| 后排 | 普通 GT 维护仓 / 能源仓 | 补外壳 |

- 某种仓的**原型找不到** → 该位补外壳；
- 某种仓的**物品没凑够** → 保留原位的空气或外壳，聊天栏报缺口；
- **升级路径**：备好仓体后再点一次部署器，成功放下仓体时换下的外壳退回共享背包。放置失败则恢复外壳，未使用的仓体退回共享背包；
- 被其它方块占住的格子不动，报告"被挡"。

仓体放置走 GT `ItemMachines` 同款管线（大 MTE ID 存在方块实体里），所有者记为部署玩家。

### 普通 GT 维护仓

部署器保留结构任一仓位上已有的 GT 维护仓，并重新分配原定维护仓位。结构里没有维护仓时，部署器从三级材料来源取用一个 GT 普通维护仓。维护与结构判定按 GT 原版规则执行。

旧存档中的免料维护仓会在原位加载为普通手动维护仓，配方已移除。`minerAutoMaintenanceMetaTileId`（默认 32702）仅用于读取旧仓体。已有存档请保留原 ID，客户端与服务端须一致。

### AE 采矿枢纽覆盖板

只能贴在采矿场/油气钻机的**主控制器**上（正面除外，整机限一个），通过 AE 无线发信器定位
ME 网络（跨维度可、零线缆），每 20 tick（可配）搬一轮：

- **补给**：采矿场每次采矿扣液前从 ME 补满可接收钻井液的实体输入仓，ME 输入仓仍按 GT 原版供液；
  采矿管道按间隔补进输入总线（`minerIoPipeBuffer`，默认 64）；油气钻机只补管道。
- **回收**：普通输出总线从物品槽搬矿物，ME 输出总线从待发送缓存搬矿物。普通总线每槽和 ME 总线每仓每轮最多搬 128 件。油气输出仓每仓每轮最多搬 4,000 mB。
- 每次搬运从发信器所在网络的能源缓存**扣 AE 电**（与 AE2 导入/导出总线同一套 `poweredInsert/poweredExtraction`
  功耗模型），网络没电就安静待机；
- 发信器离线/冲突/不同队伍时安静待机，GUI 与 tooltip 显示链路状态。

产线闭环示例：输出总线里的矿物进 ME → 合成 CPU 补货 → 管道/钻井液从 ME 出 → 机器不停机。

### 采矿区域档位（覆盖板 GUI，仅采矿场）

覆盖板 GUI 第二行 `< 采矿区域：原版 / ×2 / ×3 >`：把采矿场的采矿范围按该等级**原版半径的倍数**放大
（区域 = 2×半径 个区块宽）：

| 采矿场等级 | 原版 | ×2 | ×3 |
|---|---|---|---|
| 1 级 | 6×6 | 12×12 | 18×18 |
| 2 级 | 8×8 | 16×16 | 24×24 |
| 3 级 | 12×12 | 24×24 | 36×36 |
| 4 级 | 18×18 | 36×36 | 54×54 |

语义（**一次性应用**）：

- 选中档位的那一刻把倍率写进 GT 自己的区块半径配置——之后归 GT 的 NBT 管，**螺丝刀照常可调**，
  重启/重登后区域保持；
- **重摆机器**（新控制器）会回到原版半径，需要重新选一次档；
- 「原版」档 = 应用一次该等级默认半径，是给螺丝刀调乱后的恢复手段；
- 只对**采矿场**生效，油气钻机的钻井范围不受影响；
- `enableMinerAreaEnhance = false` 时 GUI 只存档不生效（老版本 GT 不带区块半径系统时同样自动失效）。

实现上走一个 mixin（`MixinMTEOreDrillingPlantBase`）：写 GT 私有的 `chunkRadiusConfig` 并复刻
`adjustChunkRadius` 的清理序列（释放当前区块 → 清矿物缓存 → 重新请求工作区块），区块仍是逐块强制
加载，放大区域不放大同时加载数。

### 配置项（futa_gtnh.cfg）

| 项 | 默认 | 说明 |
|---|---|---|
| `enableMinerDeployer` | true | 注册部署器 + 覆盖板 |
| `minerAutoMaintenanceMetaTileId` | 32702 | 仅用于兼容旧维护仓的 MTE ID，已有存档保留原值 |
| `minerIoPipeBuffer` | 64 | 采矿管道补货目标量（个） |
| `minerIoCoverInterval` | 20 | 覆盖板搬运间隔（tick） |
| `enableMinerAreaEnhance` | true | 覆盖板「采矿区域」档位生效开关（仅采矿场） |

### 配方

- 部署器：钢板×4 + 胶带 + 末影珍珠×2 + 基础电路 + 钢螺丝；
- AE 采矿枢纽覆盖板：末影珍珠 + 红石 + 铁板。

## 明确不做

- 不新建多方块、不改 GT5u 代码；
- 不用 ME 仓体（输入/输出仍走普通仓 + 覆盖板搬运），玩家想用 GT 原生 ME 仓自己换也完全兼容；
- 不自动接能源（GT 能源接线习惯各服务器不同，留给玩家）。

## 已知边界

- 结构区被地形/其它方块占用时该格跳过（报告"被挡"），不会破坏玩家的东西；
- 覆盖板搬运的网络记账与 AE2 原生总线一致，中途断电最多丢一轮的搬运量；
- 部署器不做撤销——拆掉的方块用扳手/镐正常回收。
