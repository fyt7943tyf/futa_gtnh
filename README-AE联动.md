# AE 联动：无线控制 + ME 超级对接站

两个功能都建立在 **Applied Energistics 2** 上（软联动：没装 AE2 时整个功能组不注册，模组其余功能不受影响）。配置开关在 `config/futa_gtnh.cfg`：`enableAeSignalWireless`、`enableAeSuperDock`、`dockMetaTileId`。

## 一、AE 无线控制覆盖板

把 AE2「发信器（Level Emitter）」的思路搬到 GT 机器上，并且无线化：**按 ME 网络里的库存量，隔着任意距离控制机器启停**。

### 发信端（方块）

- 放在 AE 线缆旁加入 ME 网络（需要通道，空闲功耗 0.5 AE/t）。
- **每个网络只能有一个生效的发信端**。同网络出现多个时，按（维度, x, y, z）字典序最小的那个生效，其余显示「冲突」并停止响应 —— 拆掉多余的即可恢复。
- 右键打开界面：可给信号命名（32 字符内，中英文都行）。名字只用于接收端候选列表的显示；**链接键是坐标**，随时改名都不会断链。
- 团队隔离：**只有发信端所有者本人或同队伍的玩家**能在接收端里看到并连接它。队伍用 GTNHLib 的 TeamManager（玩家用 `/team` 命令组队）；单人自己用不需要组队。
- 带 ME 安全终端的网络还会检查放置者的 **建造权限**。发信端会同步 AE 节点归属；旧存档里缺失的 AE 身份会按已保存的所有者 UUID 恢复。GTNH 队伍成员关系不等于 AE 网络授权，放置者仍需获得该网络的建造权限。相关修复见[安全归属说明](docs/AE无线发信端安全归属修复.md)。

### 接收端（覆盖板）

- 右键贴到单方块机器或多方块主控制器上（正面除外），整机限贴一个。
- 潜行空手右键覆盖板打开配置界面：
  - **发信端**：`<` `>` 循环选择同队可见的发信端（显示名字 + 状态）；
  - **监听对象**：物品走幽灵槽（**支持 NEI 拖入**），流体用装着流体的容器点击设定；
  - **阈值** 与 **触发条件**（存量 ≥ 阈值 / ≤ 阈值）；
  - **满足条件时的动作**：启用机器 / 停用机器（极性可反转）；
  - **监听间隔**：5–600 tick（默认 20 tick = 1 秒）；
  - **断联行为**：链路断开（离线 / 找不到 / 不同队）时保持现状 / 启用 / 停用（默认保持 —— ME 网络重启不会把产线意外点起来）；
  - 界面底部实时显示当前存量与链路状态。
- 机器启停走 GT 原生 `IMachineProgress`（与 GT「机器控制器覆盖板」同一条路），拆下覆盖板时机器自动恢复工作。

### 玩法示例

经典的「产物够了就停机」：一台多方块机器贴接收端，监听话梅产物 ≥ 2048 时停用机器；产线前端配 ME 接口自动补料，低于阈值自动复工。发信端与机器可以隔着任意维度距离。

## 二、ME 超级对接站（LV 单方块机器）

- 合成：钢板 ×4 + 末影珍珠 ×4 + 机器壳 + 基础电路 + 箱子（`EPE / CHC / PSE`）。
- 把 **GT 超级储罐 / 超级箱**（量子储罐 / 量子箱也支持）作为**物品**放进它的槽位，内容直接成为 ME 网络的存储 —— **不需要存储总线**，不需要把容器真的搭在世界里。
- 支持配置**优先级**（语义与 ME 存储总线一致：数值越高越优先作为写入目标，抽取从低优先级开始）。
- 内容读写全部走容器物品的 NBT（`mFluid` / `mItemStack` + `mItemCount`，与 GT 机器扳手拆除后内容随物品走同一套键）：**随时把容器取出来，放回世界就是一台正常的储罐/箱子**，反过来也成立。
- 对接站自身不耗 EU；接上 AE 线缆获得通道后生效。储罐的流体锁定（`lockedFluidName`）会被尊重。

## 技术备注（开发者向）

- 所有 `appeng.*` 类型引用隔离在 `com.futa_gtnh.ae2`（既有）与 `com.futa_gtnh.aewireless`、`com.futa_gtnh.medock`（本次新增）包内，注册入口都有 `Ae2Compat.isAvailable()` 守卫。
- 发信端 = `AENetworkTile` 子类（`REQUIRE_CHANNEL`），接收端覆盖板 = GT 新 cover 体系（`Cover` + `CoverRegistry`），对接站 = `MTETieredMachineBlock implements ICellContainer`（`AENetworkProxy` 姿势照抄 GT ME 输出仓）。
- 接收端查询不走网络包：服务端直接按（维度, 坐标）解析发信端 TE 调用查询方法；跨维度可用，目标区块未加载时按断联处理。
- 纹理为程序生成的占位图（`tools/texture/gen_ae_wireless_textures.py`），想换正式美术资源直接覆盖同名 PNG 即可。
