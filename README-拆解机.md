# 低压拆解机

LV 阶段可制作的 GT 单方块机器。合成使用一个 LV 外壳、一个 LV 电路、一个 LV 马达、一个 LV 活塞、两条单股锡电缆、三块钢板。可在 NEI 查看机器合成，以及成品的拆解用途。

每批固定消耗 **32 EU/t，40 tick（2 秒）**，共 1,280 EU。最大输入 **32 V、1A**；不超频、不并行，原生产配方的电压不限制拆解。缺电或硬锤停机时保留任务。

拆解只倒退一个生产步骤。例如 `4 个成品 ← 1 个零件 + 144 mB` 会要求放入四个成品，返还一个零件和 144 mB；不会把零件继续递归拆解，也不会向上取整返还材料。

机器读取最终工作台、GT 组装机及真实装配线配方。支持静态原版、Forge 矿辞、GT 和 GTNH 核心模组的 Universal 工作台配方，包含完整 3×3；忽略零数量的非消耗输入。合成用的 GT 工具及矿辞中的可重复使用工具参与配方校验，但不返还锤子、扳手等工具。不反转烧炼、化学反应等加工配方。NBT 必须与配方成品完全一致，装着库存或液体、带电或额外 NBT 的普通机器不能直接拆解。

矿辞允许多个候选材料时，返还 GT 指定的标准材料；ULV 至 LuV 电路返还 GT 的对应等级基础电路。使用其他模组的同类金属材料或更复杂的同级电路制作，也只返还标准物品，不能还原实际制作时选择的材料。工作台、组装机和装配线使用相同的归一化规则。矿辞候选数量必须一致，标准物品必须在该候选列表内，多个可用矿辞的标准物品必须一致；没有明确标准的类别继续跳过，不按列表顺序任选材料。更高等级电路仅在 GT 明确指定标准物品时支持。

动态配方、通配符、容器返还、带状态的替代材料，以及归一化后同一成品仍有不同生产材料清单时，默认跳过。LV 研磨机已在开发环境确认收录，仍只反转一个生产步骤。

加载完成时在 `config/futa_gtnh-disassembler-report.txt` 写入候选、接受和跳过原因，以及最终容量。接受条目列出实际返还物品和数量，无法统一的矿辞条目列出候选物品，便于排查。有限覆盖不保证所有模组来源的材料循环都已排除。

物品输出至少 **36 个真实槽**，流体输出至少 **8 个独立罐、每罐 64,000 mB**。按当前允许拆解的最大批次增加槽数、罐数和罐容量。物品按实际堆叠上限分堆，输出槽和罐只允许取出。界面可分别翻页查看物品和流体，用空容器点击指定流体槽取液。NEI 将较大批次分为编号页面，所有页面仍属于同一次拆解。拆解类别默认使用排序值 10000，排在普通合成和 GT 生产机器之后；NEI 自动生成的排序值 0 会恢复为此默认值，手动设置的非零排序值保留。

背面可通过漏斗、带抽取能力的管道/覆盖板或共享终端抽取物品和流体；其它侧面接收成品。电缆接任意非正面。任务开始前检查全部产物空间，完成时一起结算；不截断、丢弃或部分结算。重启保存原输入、完整产物计划和进度，后续配方目录改变不会重算已开始的任务。拆掉机器时，GT 掉落普通库存及未完成的原输入，罐中液体随机器物品保存，放回后恢复。

`enableDisassembler` 控制注册；`disassemblerMetaTileId` 默认 **32700**。两端配置必须一致，遇到 ID 冲突启动会清楚报错。首次使用可调整空闲 ID，已有存档不能随意更改 ID。持久化的输出槽位编号及容量不会因为新目录缩小而截断。

开发依赖 GT5U 5.09.54.175。2.9.0 RC1 的 5.09.54.183 接口已核对；最终游戏行为仍需在实际整合包验证，源码编译不等于全整合包兼容性证明。
