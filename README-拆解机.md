# 低压拆解机

LV 阶段可制作的 GT 单方块机器。合成使用一个 LV 外壳、一个 LV 电路、一个 LV 马达、一个 LV 活塞、两条单股锡电缆、三块钢板。可在 NEI 查看合成与拆解用途。

每批固定 **32 EU/t、1A、40 tick（2 秒）**，共 1,280 EU；不超频、不并行，原生产配方的电压不限制拆解。缺电或硬锤停机时保留任务。只倒退一个生产步骤，不递归拆材料。

## 配方规则：GTNL 微光

配方生成、优先级、材料替换、矿辞回退及黑名单按 GTNL 微光迁移，弃用旧的最终工作台扫描与冲突禁用规则。参考 `ABKQPO/GT-Not-Leisure` 的 `dev-290`，固定提交 `c9614667efbbcbc5b9eed89c76807caeea4b1e5e`。

- 优先采用已安装 GTNL 的微光转换及硬覆盖，然后读取组装机、可视装配线、太空组装机，最后使用捕获的 GT 工作台配方。
- 工作台在 `GTShapedRecipe` / `GTShapelessRecipe` 构造时捕获原始参数，**只收录成品为 GT `ItemMachines` 的配方**，使用 GT 自带反转函数。包含完整 3×3，不再重建虚拟工作台校验。原版、Forge 和 NHCore Universal 配方不会另外全量扫描。构造时捕获的路线之后被移除，也仍按微光记录处理。
- 工作台的工具矿辞和 GT 工具不返还；缺少 GT 标准物品的矿辞按 GT 反转函数选择矿辞候选，缺失矿辞可被单独忽略，不因该项禁用整个成品。NBT 保留、附魔等工作台标志不构成额外禁用条件。
- 组装机按成品分组，使用第一条生产路线；按其他路线相同槽位、相同前缀降低特定材料成本。不同材料路线不会整项禁用，概率、禁用、假配方及自定义配方不再由旧规则额外过滤。组装机仍要求只有一个成品。
- 自动组装机及 GT 工作台返还使用微光的完整材料替换表：廉价替换、Any 材料处理、磁性材料与退火铜还原、ULV～MAX 的 NHCore 最便宜电路、原版木材/圆石/钻石等矿辞替换。非耐久通配符元数据改为 0；耐久通配符保留；带容器材料单独剔除。可视装配线、太空组装机和硬覆盖原样返还原料，不套用这套材料转换。
- 自动组装机及 GT 工作台排除 GT 工具、电路、矿石/碎矿、已有解包机配方的物品，以及微光完整黑名单：超导线圈、石墨烯粉、真空管、原理图、ZPM、创造维护仓、特定铁路、混合金属锭、水槽墙、LV～EV 变压器、AE 合成终端/透明致密线缆及防辐射板。装配线、太空组装机及硬覆盖遵循微光各自的分支，不额外套用自动输入黑名单。
- 目录去重忽略 NBT 并考虑批次数量；实际执行按 GT 的物品、元数据通配符和 NBT 规则匹配。因此普通配方不会接受带额外电量、库存或液体 NBT 的机器。

未安装 GTNL 时迁移算法独立运行，不引入 GTNL 的其它机器、物品或生产配方。安装 GTNL 时等待其首次 tick 加载转换表，再导入；GTNL 配方表不被修改或清空。太空组装机仅在安装 Intergalactic 时读取。

## 机器执行与存储

保留原始生产批次，不再按最大公约数缩小：`4 成品 ← 8 零件 + 144 mB` 需要 4 个成品，返还 8 零件和 144 mB。每次只执行一批，剩余成品留在输入栏。微光的世界交互会即时按批次数量放大返还；机器用相同转换规则，每批处理 2 秒。

超过单个合法物品堆叠的批次可分多次投入，原成品暂存到内部保护槽，GUI 显示“待补足批次”；凑齐后才开始耗电。内部暂存完整数量写入存档，拆机前拆分为合法掉落堆叠，不通过 GUI 同步超大物品堆。

至少 **36 个真实物品输出槽、8 个独立流体罐，每罐 64,000 mB**。按最大配方增加槽数、罐数和容量；已有或先于微光目录加载的机器自动扩容，保留库存及任务。流体原料及导入的微光流体包转换为真实流体输出，保留数量和 NBT。

物品和流体各自翻页，输出只允许取出；空容器可从指定流体槽取液。背面供管道/覆盖板或共享终端抽取，其它侧面接收成品，电缆接任意非正面。开始前校验全部空间，完成时一起结算；阻塞时暂停，不丢弃或部分结算。旧存档中的进行中任务继续按已保存的产物计划结算。

拆掉机器返还库存和未完成的原输入；罐中液体随机器物品保存。NEI 大批次显示编号页面，排序仍默认 10000，位于日常合成及 GT 加工类别之后。只拿一个成品查询用途也能看到需要多件成品的拆解配方。网页配方缓存内部版本更新为 15，模组版本不因此改变。

`enableDisassembler` 控制注册，`disassemblerMetaTileId` 默认 **32700**。客户端和服务端应使用同一测试包及配置，已有存档不可随意更改 ID。报告为 `config/futa_gtnh-disassembler-report.txt`，包含来源数量、失败路线、实际物品/流体返还及容量。
