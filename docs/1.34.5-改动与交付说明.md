# 1.34.5 改动与交付说明

完成加载和兼容快照的四项优化，保留逐项完整性检查及旧服迁移保护。

- 单次加载复用物品 ID/流体名称的存在性查询，最近值直接命中，另有最多 64 项的结果记忆；不同类型较多时停止字典增长。加载结束即丢弃，不缓存数量校验或跨加载保存缺失模组判断。
- 单元件资源直接记录首枚元件，仅跨元件时分配额外列表；耗空时依次提升/收缩并正确移除关联。数量继续读取真实原生元件。
- 原生兼容池快照直接生成最终只读列表和不可变条目，省去中间 Set/Entry 和再次复制；保留稳定资源引用快照及实时数量读取，旧解码器路径不变。
- 有界预留索引/元件集合容量，复用 63 项校验缓冲并在每枚元件开始前全部清零。预分配提示不是存储上限，更多资源仍正常增长并完整校验。

本轮主要减少分配，CPU 加载耗时仅小幅改善。同机三个独立 JVM、8192 种资源配对测试：无 NBT 解压＋挂载从 8.44 ms 降至 8.19 ms，带 NBT 从 12.61 ms 降至 12.31 ms；普通 AE 分别为 6.35 ms、9.76 ms，仍未完全持平。带 NBT 首次兼容池列表快照（含已解压挂载）从 13.26 ms 降至 12.42 ms。

带 NBT 已解压挂载累计对象分配约 6.31→5.65 MiB，减少约 10.5%；带 NBT 首次兼容池列表快照约 10.69→9.38 MiB，减少约 12.3%；无 NBT 首次池快照约减少 17.1%。这些是累计分配量，不是常驻内存。完整方法、分位数和九份原始记录见 `docs/1.34.5-原生AE四项优化性能对比.md`。

- build / spotlessCheck、原生存储 40957 项回归通过，新增 2651 项覆盖缓存预算及跨加载刷新、缓冲清零、快照独立/不可变、绕过中间条目集，以及单枚/多枚/提升/收缩/耗空/补回转换。
- 原有 2400 组冻结/新版完整性随机对照在样本之间复用上下文继续通过，缺行、数量、原版数值转换、溢出、未知模组和额外字段的隔离/拒绝决策保持正确；原有 46 项迁移和全部产线/IO 回归继续通过。
- 每通道 16385 种、共 32770 种资源越过预分配提示后仍完整加载，81928 项断言通过；该轮作为正确性检查，不作为稳定性能结论。
- 六轮配对基准共 155574 项、两轮完整路径共 434208 项断言通过；两种保存负载各在独立进程通过 24580 项完整库存/缓存重挂载核对。发布控制器 30 项测试通过。
- 两套真实隔离客户端/集成服务端通过旧共享存档自动迁移和已有 1.34.4 原生存档重启；原 UUID、完整 NBT、长数量、限额、未决托管和已消耗数量正确，原始旧文件字节未变。保存/重挂载/重新加载及坏版本保护通过。
- 公共 ME、跨维度原生盘、产线终端、双总线实际 56 件/12000 mB 统计、零库存历史和两套各 26 个 GL 页面通过。仅使用开发存档，未操作生产服。
