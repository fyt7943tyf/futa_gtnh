# 寻物魔杖：已摆放木箱的匹配

方块页签中的原版木箱物品元数据为 0，摆放后的箱子用元数据 2–5 表示朝向。原逻辑直接比较物品与世界元数据，会漏掉正常摆放的木箱；空箱与装有物品的箱子都受影响。

现在仅对 `BlockChest` 方块按其掉落物变体归一后比较。箱型仍先按方块实例区分，普通箱与陷阱箱不会互相匹配，羊毛颜色等其他方块变种的匹配逻辑保持原样。搜索与追踪复查共用这一规则，转动箱子也不会丢失目标。

物品页签仍按库存中的目标物品查找有货的箱子，空箱不会命中。扫描只读取已加载区块，不加载新区域，也不修改箱内物品或 NBT。

`verifyLocatorChests` 已加入完整 `build` 检查，覆盖原版木箱和陷阱箱各朝向、空/满库存、再次搜索、旋转后的追踪复查、不同方块变种、最近有货箱、负坐标及未加载区块。修复前已复现朝向 2 的空箱漏检。
