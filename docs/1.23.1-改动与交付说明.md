# futa_gtnh 1.23.1 改动与交付说明

日期：2026-10-03。版本来自 `version.txt`，发布分支 `main`。

## 修复

共享终端的虚拟槽位取出后仍然显示库存，原版 GUI 会把快速 Shift 连点识别为双击，在鼠标按下派发取出后，又在释放时转移一次。原代码可复现点 5 次取 6 组或 7 组，额外取出的物品也扣减仓库库存。

现在共享格的空手 Shift 左键/右键在按下时仅派发一次请求，消费该手势的拖动和释放事件；包含原版槽位命中的一像素边缘，并清理窗口外丢失释放事件的标记。保留普通点击取到光标、普通双击收集、持有光标的存入、玩家背包 Shift 双击存入及搜索框失焦行为。

修复发生在客户端 GUI，未改变网络包格式、动作编号、服务端取出算法或存档格式。需要升级客户端才能获得点击修复；两端发布包统一为 1.23.1。

## 验证

```powershell
.\gradlew.bat spotlessApply build spotlessCheck --offline -I tools/gradle/spotless-cache.init.gradle
```

构建、Spotless、Checkstyle、共享存储只读 API 回归、拆解机/背包转移 208 项断言及新增 `verifyTerminalClicks` 均通过。新增测试执行真实 GUI 按下/拖动/释放路径，固定键盘和时钟，使用真实交换/存储算法验证库存总量；慢点、一次双击及连续快点都为 5 次按下、5 次取出、0 次释放阶段取出。另覆盖槽位边缘、释放到背包、提前松开 Shift、光标异步变化、丢失释放事件、Shift 右键、光标双击收集和背包 Shift 双击存入。

测试运行器和键盘/时钟替身独立于主源码集，未进入发布 jar。详见 `tools/terminal-click-check/README.md`。

`runClient17` 已完成开发环境的 73 个模组加载和声音引擎启动。界面事件验证使用独立 JVM 的回归运行器，未完成完整 GTNH 2.9.0 的实际多人点击联调。开发环境仍有既有的缺失纹理及 GT orbital shader 错误。本次未改动相关资源。
