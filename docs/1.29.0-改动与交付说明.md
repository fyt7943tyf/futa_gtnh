# 1.29.0 改动与交付说明

本版本是一个次版本更新，核心是两项全新的 **Applied Energistics 2 联动功能**（软联动：没装 AE2 时整个功能组不注册，其余功能不受影响）。详细玩法见 [README-AE联动.md](../README-AE联动.md)。

## 新功能

### AE 无线控制覆盖板（发信端方块 + 接收端覆盖板）

把 AE2「发信器（Level Emitter）」的思路搬到 GT 机器上并无线化：**按 ME 网络里的库存量，隔着任意距离（含跨维度）控制机器启停**。

- **发信端方块**：贴 AE 线缆加入 ME 网络（需通道，空闲功耗 0.5 AE/t），右键界面可命名（32 字符，中英文均可）；
  - 每个网络只能有一个生效的发信端——多放时按（维度, x, y, z）字典序取最小者，其余显示「冲突」并停止响应，拆掉即恢复；
  - **节点隔离**：只有发信端所有者本人或同队伍玩家（GTNHLib TeamManager，玩家用 `/team` 命令组队）能在接收端里看到并连接它；单人自己用无需组队。
- **接收端覆盖板**：右键贴到单方块机器 / 多方块主控制器上（正面除外，整机限一个）：
  - 选发信端（仅列同队可见项，显示名字与状态）；
  - 监听物品走幽灵槽（**支持 NEI 直接拖入**），监听流体用装着流体的容器点击设定；
  - 阈值 + 触发条件（存量 ≥ / ≤ 阈值）；满足条件时可配置「启用机器」或「停用机器」（极性可反转）；
  - 监听间隔 5–600 tick（默认 20 tick）；断联行为三选一：保持现状（默认）/ 启用 / 停用；
  - 界面实时显示当前存量与链路状态（正常 / 未选择 / 找不到 / 不同队 / 离线 / 冲突 / 未设监听）。
- 机器启停走 GT 原生 `IMachineProgress`（与「机器控制器覆盖板」同一条路），拆下覆盖板时机器自动恢复工作；接收端查询在服务端直连完成，不走网络包。

### ME 超级对接站（LV 单方块机器）

- 合成：`EPE / CHC / PSE`（钢板 ×4 + 末影珍珠 ×4 + LV 机器壳 + 基础电路 + 箱子）；
- 把 **GT 超级储罐 / 超级箱**（量子储罐 / 量子箱也一并支持，同一套 NBT 结构）作为**物品**放入槽位，内容直接成为 ME 网络存储——**不需要存储总线**，也不需要把容器真的搭在世界里；
- **可配置优先级**：语义与 ME 存储总线一致（数值越高越优先作为写入目标，抽取从低优先级开始）；
- 内容读写全部走容器物品 NBT（`mFluid` / `mItemStack` + `mItemCount`）：随时取出，放回世界就是一台正常的储罐/箱子，反之亦然；尊重储罐的流体锁定；机器本身不耗 EU，接 AE 线缆获得通道后生效。

## 配置项（config/futa_gtnh.cfg）

| 键 | 默认 | 说明 |
|---|---|---|
| `enableAeSignalWireless` | `true` | 注册 AE 无线控制（需装 AE2） |
| `enableAeSuperDock` | `true` | 注册 ME 超级对接站（需装 AE2） |
| `dockMetaTileId` | `32701` | 对接站的稳定 GT MTE ID，冲突时修改；已有世界不可随意更换，两端需一致 |

## 其他改动

- 新增网络包判别号 32/33（发信端改名 C2S / 状态快照 S2C），沿用「只增不改」约定；
