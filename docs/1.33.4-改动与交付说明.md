# 1.33.4 接收端覆盖板界面错位修复

修复 1.33.2 之后玩家截图反馈的「AE 无线接收端覆盖板」界面文字错位：监听类型行与三个选项组（触发条件 / 满足条件动作 / 断联行为）的**第一行**文字相对按钮偏上。

## 根因与修法

- **根因**：这些行被包在 `Flow + positionRow` 的嵌套里。MUI2 的 Flow 对交叉轴（垂直方向）居中有一个内部限制——布局时尺寸尚未算好的子控件会被**跳过定位**，停在顶对齐；而 1.33.2 加的 `verticalCenter()` 是相对定位锚点（`topRel(0.5)`），与 Flow 自己的居中互相打架。选项组首行恰好落在两种机制都不生效的组合上。
- **修法**：三个选项组网格改为**直挂列**，参数逐字对齐 GT 机器控制器覆盖板模板（`CoverControlsWorkGui`）——Grid 单元格按 `(height - area.height) / 2` 数学居中，不经过 Flow；监听类型行改为 GT 液体模式按钮同款的**图标开关 + 悬停提示**（文字不再贴着按钮摆放），并保留「监听类型」静态标签在网格内居中。
- 发信端 / 阈值 / 监听间隔 / 状态行在截图中已确认对齐正常，维持原结构不动。

## 实机验证

- 打开覆盖板界面：九行文字与按钮/输入框垂直居中，左缘对齐（对照 1.33.2 截图中的偏上行）。
- 监听类型图标按钮：悬停显示「监听物品 / 监听流体」，点击切换模式后两侧槽位行为不变。
- 全控件点击一遍（沿用 1.33.2 的验证清单）确认无回归。

## 兼容

客户端单独更新即可（纯界面改动，无网络协议与存档变化）。
