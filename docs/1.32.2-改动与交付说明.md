# FutaGTNH 1.32.2

日期：2026-10-21。基于正式版本 1.32.1。

## 修复：IO 主动输出抽不到存储总线里的东西

1.32.1 的 IO 节点 / 共享终端主动输出走的是 `extractItemDirect` / `extractFluidDirect`，
只从共享存储池取料。总线容器虽然计入聚合库存，但池子里没有对应物品/流体时，
输出不会去总线目标里抽；典型现象是总线贴着装满氨的超级缸，池子为空，
往输入仓输出氨时一直送不进去。

现在：

- 新增 `SharedStorage.extractItemExcluding` / `extractFluidExcluding`，从
  **总线容器 + 池子** 的聚合库存抽取；
- IO 节点 / 共享终端的主动输出改走这两个入口，物品和流体都生效；
- 抽取时排除输出目标自身挂着的总线，避免把刚送进目标容器的东西又抽回来；
- 优先级顺序不变：负优先级总线 → 池子（0）→ 非负优先级总线；写入方向仍是
  非负优先级从高到低 → 池子 → 负优先级从高到低；
- 回滚路径仍然直接回池子，不经过总线，避免上限/总线阻挡造成丢失。

## 验证

- `verifyStorageBus`：**130 项**通过（新增总线目标流体抽取、排除目标自身）；
- `verifyTerminalIo`：**5591 项**通过，新增
  `active fluid output can drain a storage-bus-attached tank`：
  总线贴着 3000 mB 水箱、池子为空，IO 输出到另一个空罐后目标收到流体、源水箱减少；
- `gradlew build` 通过。

- 客户端和服务端可以继续按 1.32.1 的协议互通，但建议同时更新到本版；
- 1.32.1 的既有发布内容不受影响。
