# 1.33.2 IC2 反应堆布局工具 + MUI 界面审计修复

本版包含两块：新功能「IC2 反应堆布局工具」（PR #8，随合并把网络包号调整为 39-42，避开离线服外观甲身份同步的 37 和迅步光环的 38），以及 MUI 界面全面审计后的 11 项修复——其中一项是玩家点击即崩的线上崩溃。

## IC2 反应堆布局工具（PR #8）

- **Shift + 右键反应堆**：服务端权威记录当前摆放为布局档案（自动命名，上限 `reactorToolMaxLayouts` 条，默认 100），落盘 `<存档>/data/futa_gtnh_reactor_layouts.dat`（tmp 原子写 + .bak 轮换 + 定期自动保存）。
- **普通右键**：纯客户端浏览器——布局列表、54 格预览、需求清单（背包/共享背包可用量、NBT 精确与否标注）、改名（40 字符上限）、删除。列表是全服共享的。
- **部署**：先清空回收（旧件入共享背包）再全量铺设；取料玩家背包优先、共享背包补足；**三级 NBT 匹配**（精确 → 同物品+耐久宽松取最接近全新 → 缺料报告），解决带损耗 NBT 的燃料棒无法等值请求的问题；被顶替的数量会在聊天栏明说。
- **一键外壳**：满配 6 反应堆仓时用压力容器填满 5×5×5 壳层 98 格；只往空气/可替换方块放、跳过生物站位，缺料摆多少算多少，余料退回。只摆容器本体，检修孔/流体端口需自换（聊天栏有提醒）。
- 服务端校验闭环：手持工具、潜行、8 格距离、功能开关；IC2 依赖收窄到 `ic2.api` 三个公开接口，反射失败自动退回手数反应堆仓。

## MUI 界面审计修复（11 项）

对全部 ModularUI 2 界面审计后修复（详见仓库根目录《README-MUI界面审计.md》），重要度从高到低：

1. **崩溃修复**：AE 无线接收端覆盖板配置界面有 5 个同步值（阈值/触发条件/动作/监听间隔/断联行为）未注册，点击对应按钮或输入数字必崩客户端——本次全部补注册。
2. **服务器英文混排**：接收端覆盖板状态行、ME 超级对接站信息行的本地化原先在服务端做，专用服务器上中文客户端会看到英文——改为同步原始数据、客户端本地化。
3. **样式统一**：接收端覆盖板界面按 GT 覆盖板惯例重排——九行统一左缩进与行距；图标语义统一（启用/停用=勾/禁止、条件≥/≤=红石亮/灭、断联保持=锁、物品/流体=液体模式对）；字号统一 1.0；行内动态文本垂直居中修正。
4. **轻量点修**：对接站字号四档收敛两档；拆解机页码固定宽度居中（位数变化不再跳动）；发信端界面标题行距与输入框双重描边。
