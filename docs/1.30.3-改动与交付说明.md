# 1.30.3 改动与交付说明

- 共享终端和 IO 节点主动输出时，先尝试手动选择的物品，再用剩余额度输出矿辞匹配物品；缺货或目标拒收手动物品时继续尝试矿辞物品。
- 共享终端提供给管道的可抽取槽位按手动优先排列，保持槽号与精确物品（含 NBT）的绑定；管道自身的扫描策略可能影响实际抽取顺序。
- 手动列表为空时恢复纯矿辞筛选，不再受历史取消记录影响；旧存档的空手动列表自动清除这些记录。矿辞匹配继续直接使用 AE2 矿典过滤卡的匹配器，勾选预设仍作为额外的矿辞条件。
- 迅步新增独立的植物魔法加速开关，默认关闭；与作物加速共享范围和强度，支持白雏菊、魔力池充能／转化、火花、魔力脉冲等。见《迅步-植物魔法加速》。

本次不更改终端网络协议和存档字段；建议客户端和服务端同时更新，以保持筛选提示与实际行为一致。
迅步设置包在尾部增加可选开关，读取旧包时保持当前开关状态。

验证：`build spotlessCheck`；终端 IO 回归 5482 项、迅步植魔回归 144 项、库存与筛选界面回归 47 项、发布规则测试 23 项。未进行游戏内客户端／服务端联调。
