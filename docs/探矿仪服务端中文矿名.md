# 探矿仪服务端中文矿名

FutaGTNH 在服务端生成 Detrav 电动探矿仪结果时，将识别到的矿石名称转换为简体中文。适用于 `gregtech:gt.detrav.metatool.01/106` 及复用相同探矿数据包的其他等级。

## 安装与兼容性

- 替换服务端的 FutaGTNH jar，重启后重新扫描。单机世界使用集成服务端，也会生效。
- 不需要修改 GregTech jar；本功能不要求客户端同步更新 FutaGTNH。
- GT 原有数据包格式、对象编号、颜色、坐标及图标使用的材料标识保持原样。旧客户端可以直接显示收到的中文名称。
- 这是服务端统一发送的简体中文，客户端选择其他语言时也会收到中文矿名。
- 不修改 Minecraft 或 GregTech 的全局语言设置。

## 译名来源

模组内置 GTNH 2.9.0 `GregTech_zh_CN.lang` 中的 1514 个材料译名，保存在 `assets/futa_gtnh/prospector/zh_CN.lang`，独立于普通客户端语言资源。

每次服务端启动时，会读取服务端运行目录的 `GregTech_zh_CN.lang`，用其中的材料译名覆盖内置词典。文件不存在时仍可使用内置词典。该文件只读，不会写回；修改后需重启服务端。

支持 GT 的 Forge 配置格式：

```text
languagefile {
    S:Material.copper=铜
    S:Material.zircon=锆石
}
```

名称按普通矿石与小型矿石分别组合，例如 `铜矿石`、`小型铜矿石`。基岩种类不额外附加到名称中，沿用 GT 对同材料矿石的展示方式。

GT 的 `OreManager` 无法识别材料，或材料没有对应译名时，保留原始名称；可以在服务端中文文件中补充 `Material.*` 译名。此功能只处理矿石名称，地下流体和其他界面文字不在本次改动范围内。

## 验证

```powershell
.\gradlew.bat verifyProspectorChineseNames
.\gradlew.bat build spotlessCheck
```

回归检查通过 LaunchWrapper 实际应用生产 Mixin，在服务端环境中检查普通/小型矿石、重复矿石分组、原始 GT 数据包编码解码、颜色坐标和材料标识、词典覆盖及缓存失效、缺失译名回退，以及全局语言不受影响。

游戏内复核：使用 UHV 电动探矿仪重新扫描有普通铜矿石和小型铜矿石的区域，检查列表及悬停文字显示中文，并逐项点击确认地图筛选和高亮正常。服务端日志应出现“探矿仪服务端中文矿名已启用”。
