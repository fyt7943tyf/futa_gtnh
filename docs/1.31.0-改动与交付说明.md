# FutaGTNH 1.31.0

日期：2026-10-20。基于正式版本 1.30.4。

## 新功能：共享存储总线

新增「共享存储总线」方块。把它贴在箱子、GT 机器、输入/输出总线、储罐等容器旁边，
该容器的物品与流体会进入全服共享存储的聚合库存：

- 共享终端、AE 共享背包元件、IO 节点和 GT 管道看到的都是「池子 + 总线容器」的合计数量；
- 从共享存储取东西时按优先级从对应容器扣除，往共享存储放东西时按优先级先填对应容器；
- 支持**读写 / 只读 / 只写**三种访问模式；
- 支持**优先级**：写入时高优先级先填，抽取时低优先级先抽，共享存储池按 0 处理；
- 物品筛选 9 格、流体筛选 9 格，支持白名单 / 黑名单与**精确 / 模糊 / 矿辞**匹配；
- 配置界面可切换目标面，目标面纹理同步变化；
- 目标容器区块卸载时，其库存暂时从共享存储视图中消失；重新加载后自动恢复；
- 总线只是实时映射，不会主动把容器内容搬进池子；拆掉总线不会删除容器里的东西。

## 兼容性与行为说明

- 新增方块、方块实体、GUI id `9`，以及网络包 `#34`（S2C 配置同步）和 `#35`（C2S 配置上行）；
  既有网络包编号、存储存档格式和终端协议不变。**客户端与服务端需要同时更新**才能使用总线。
- 共享存储的按条目上限现在把可读/只写总线库存计入总量：已有库存超过上限时不会被删除，
  但自动化写入会被拒收，手动写入和取出仍可用。
- IO 节点 / 共享终端的主动输出只从池子取料，避免把总线容器里的东西又推回它自己；
  主动抽入直接进池子，源容器本身挂着总线时也不会形成写回循环。
- `/futashared clear` 只清空共享存储池，不会删除总线接进来的容器内容；命令提示已同步修改。
- 新增配置项 `enableStorageBus`（默认开）和 `storageBusRefreshTicks`（默认 10 tick）。
- 新增合成配方；方块纹理由 `tools/texture/gen_storage_bus_textures.py` 生成。
