# futa_gtnh 1.23.0 改动与交付说明

日期：2026-10-03（开发与启动检查始于 2026-10-02）。版本来自 `version.txt`，发布分支 `main`。

## 改动

- 新增 LV GT 单方块拆解机，便宜的 LV 合成，固定 32 EU/t、最大输入 32 V/1A、每批 40 tick（2 秒），不超频、不并行、只反转一个生产步骤。
- 加载完成后读取最终工作台、GT 组装机和真实装配线配方；精确批次、NBT 身份、非消耗输入过滤、冲突路线跳过。按来源和跳过原因写入 `config/futa_gtnh-disassembler-report.txt`。动态或未适配配方、容器和不同矿辞替代材料不自动反转。
- 独立真实输出库存和多个真实流体罐，按目录最大批次计算容量；物品按实际堆叠上限分堆，界面和 NEI 分页。开工前检查完整产物空间、输入托管、完整产物计划和进度持久化，完成时一次结算；存档保留已有槽位和容量。
- 固定 MTE ID 默认 32700，注册时检查冲突，并排在 GT/GT++ 机器注册之后。开发启动发现的旧候选 ID 31780 已废弃，它属于 GT++ HV Chisel Bus；未发布到用户世界。
- 共享终端空格＋左键支持在主背包或快捷栏的空/非空槽位触发，只存入主背包 27 格，保留快捷栏、护甲和光标。复用已有服务端 `SCOPE_MAIN` 请求，未新增或更改网络包编号。

使用说明见 [拆解机](../README-拆解机.md) 和 [共享背包](../README-共享背包.md)。两端均安装 1.23.0，拆解机开关及 MTE ID 配置须一致。

## 验证

本机使用 JDK 25，Gradle/JDK 缓存位于工作区；Spotless 初始化脚本仅处理本机缓存路径。

```powershell
$env:GRADLE_USER_HOME = "$PWD\.gradle"
.\gradlew.bat spotlessApply --offline -I tools/gradle/spotless-cache.init.gradle
.\gradlew.bat build spotlessCheck --offline -I tools/gradle/spotless-cache.init.gradle
```

构建、Spotless、Checkstyle、既有共享存储只读 API 回归及新增拆解机/主背包转移的 **208 项断言通过**。新增回归用真实 MC/Forge/GT 类及内存模拟世界，覆盖精确批次、NBT、催化剂/容器、1/16/64 堆叠上限、50 槽物品、多种及 NBT 不同的流体、空间不足不消耗、缺电暂停、存档容量保留和继续完成、1280 EU/批、真实 GT 库存接口、按类型跨罐 drain、轮询输出和主背包转移数量守恒。回归运行器不打入正式 jar。

`runClient17` 已完成开发环境模组加载和拆解目录扫描：GT5U 5.09.54.175 下 11,527 个可解析候选、3,988 条接受配方、30,939 个被阻止的成品身份；36 个输出槽、8 个流体罐、每罐 92,160 mB。数字只代表本机开发依赖集合。临时补齐了 CoFH 开发映射文件到被忽略的 `run/conf`，未修改发布依赖；GT 的 orbital shader 在本机显示不可用，不涉及拆解机。未完成游戏内点击、管道/覆盖板及拆机联调，也未运行完整 GTNH 2.9.0 整合包。

`runServer17` 尝试停在首次启动的 Minecraft EULA 确认，未代用户接受。因此独立服务端启动检查未完成。GTNH 2.9.0 RC1 的 GT5U 5.09.54.183 源码接口和默认 ID 已核对，这不代替实际整合包运行验证。
