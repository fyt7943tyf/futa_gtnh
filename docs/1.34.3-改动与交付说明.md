# 1.34.3 改动与交付说明

继续优化公共原生 AE 的加载：取消新资源登记时重复构造的负缓存身份，缺失条目检查改用等价的注册表判空，兼容键直接从 AE 栈取得独立 NBT 副本。原生存储介质与数据格式不变，完整解码、计数核对、缺失模组整枚隔离和旧服迁移保护继续保留。

- 同机三个独立 JVM 的配对测试，8192 种资源：NBT 的解压＋挂载从 18.94 ms 降至 15.46 ms（约减少 18.4%），普通 AE 为 10.05 ms；无 NBT 从 11.22 ms 降至 10.34 ms，普通 AE 为 6.85 ms。公共检查及资源索引仍有加载开销，尚未完全等同普通 AE。
- NBT 已解压挂载的累计对象分配从 26.99 MiB 降至 14.13 MiB，约减少 47.7%。完整路径另测：公共数据加载 17.40 ms、普通 AE 11.45 ms；此路径包含额外服务元数据，不能与上面的阵列配对表混算。
- 日常随机物品＋流体取出放回继续接近普通 AE；保存格式与原生引擎保持不变。完整数据、方法及限制见 `docs/1.34.3-原生存储加载性能对比.md`，附六份配对测试和两份完整路径原始 JSON。
- 32481 项原生索引/加载回归及 46 项迁移回归通过。新增 250 项覆盖完整 NBT/哈希/可变请求隔离，以及冻结/优化加载器在缺失模组、坏计数、缺行、负数量、溢出、旧流体标签和额外未知行下的相同保护与重载结果。build / spotlessCheck、发布控制器 30 项测试通过。
- 六轮加载基准共 155574 项断言、两轮完整路径基准共 434208 项断言通过。两种保存负载在独立进程重挂载核对通过。
- 真实隔离客户端和集成服务端验证：更早旧共享文件自动迁移，已有 1.34.2 原生存档直接重启，原始旧文件不变；长数量、NBT、UUID、限额、托管和已消耗数量正确。保存/重挂载/重新加载及坏版本保护通过。
- 两套真实环境均通过公共 ME、跨维度原生盘、手持产线终端、二合一接口双总线实际流量、零库存历史和 26 个 GL 页面。测试仅使用开发存档，未操作生产服。

原生数据格式仍为版本 1，1.34.0–1.34.2 无需再次迁移；旧共享文件沿用自动迁移、备份/来源摘要核对、原子所有权提交和失败保护。网络协议及统计归属规则未改变，客户端/服务端建议一同更新。开发夹具、冻结源码及测试工具不打入发布 JAR。
