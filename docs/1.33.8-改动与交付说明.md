# 1.33.8 改动与交付说明

新增 **产线管理终端**，可以在设备旁直接选择产线并绑定 IO。

## 使用方法

- 用一本书、一个指南针和一个红石粉无序合成，也可从创造物品栏工具页获取。
- 手持终端 **Shift + 右键 IO**，确认设备名称、维度、坐标、工作面和当前归属，直接点击产线即可绑定；再次选择其他产线会转移归属。
- 绑定页面支持现场新建产线、解绑和翻页。还没产生过搬运记录的 IO 也可以提前绑定。
- **对空气普通右键** 打开完整产线管理页，查看整线或单个 IO 的物品、流体领用和回库速率。

支持共享 IO 节点、共享终端 IO 面、AE/AE2FC 的物品与流体输入输出总线、存储总线、方块式和面板式 ME 接口，以及实现 AE 网格代理的 GT ME 仓室/总线。线缆上应点到具体总线或接口面板；共享 IO 与 AE 总线按工作面区分，GT ME 仓室与方块式接口按整机绑定。

## 权限与兼容

- 创建产线和修改绑定仍要求 **OP 4**，普通玩家可查询。
- 绑定目标由服务端按实际设备固定。切换掉手持终端、离开目标超过 8 格、拆换目标或卸载区块后，绑定窗口失效。
- **客户端和服务端应同时升级至 1.33.8**。新增终端打开请求先检查服务端能力，旧协议编号不变。
- 现有库存与产线文件格式不变，产线 UUID、名称和已有绑定继续沿用。
- 绑定保存设备归属；流速仍表示已观察到的库存领用和回库，不会新增机器内部生产采样，也不会补齐 AE CPU 直接投料路径的设备归因。
