# FutaGTNH 1.28.1

## 库存上限管理页

- 共享终端右上角新增「上限」按钮，方块终端和 B 键远程终端均可打开。
- 选择物品／流体、搜索、翻页，输入最大库存数量后保存；支持只看「已设上限」。
- 库存为 0 的已配置条目也能继续查看、修改或取消上限。
- 上限范围为 0 到 `Long.MAX_VALUE`；0 拒绝自动化入库，留空或取消上限恢复不限。
- 上限仍只约束自动化，手动存入可超限。达到上限或超限时自动化拒收，取到上限以下后恢复接收。
- 调低上限、更新模组、保存和重启都不会删除现有超限库存；页面显示真实库存和拒收状态。
- 修复设置上限时被单次搬运数量限制静默截断的问题，以及断线后残留上限缓存的问题。

## IO 输出白名单

- IO 节点和终端面配置的筛选页新增独立「已选白名单」区域，与搜索结果同时显示。
- 条目支持翻页，库存为 0 也会显示，单击取消当前面、当前类型的该条目输出。
- 取消物品输出优先于重叠的矿辞预设／自定义前缀，重新选中该物品可恢复。
- 取消记录随配置保存，其他面、其他物品和流体不受影响。

## 更新与兼容

- 客户端与服务端同时更新至 1.28.1。
- 共享仓库存档格式保持不变，无需转换；不清空库存、不按上限裁减数量。
- IO 配置新增可选 `excludedItems` 字段保存明确取消的物品。旧配置读取时为空，保持原行为。
- 上限编辑复用既有操作和快照协议；AE2 的服务端 `ae2CellObeyLimits` 配置继续按原规则生效。
