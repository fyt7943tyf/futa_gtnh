# futa_gtnh 1.22.0 改动与交付说明

整理日期：2026-10-02。发布主线为 `main`，版本号来自 `version.txt`。

## 当前改动

- 共享仓库新增只读 API v1，供 AE2-WEB 等可选接入方读取唯一的全服物品和流体仓库。提供就绪状态、generation/revision 和原子快照，保留 long 数量；返回原型及 NBT 为副本，不开放写入或权限接口。详见 [只读仓库 API](AE2-WEB-只读仓库API.md)。
- 终端输出改为六面独立白名单，主动推送与被动抽取使用同一面的筛选；空白名单禁止输出，输入不受输出筛选限制。支持精确物品/NBT、流体、矿辞预设与自定义前缀，迁移旧的全局筛选配置。
- 调整终端输出页的方向选择、虚拟物品槽位及缓存失效；移除旧中键输出选择动作和对应同步包，保留原包号空位，不重新编号其他消息。
- 更新中英文界面文本、共享背包文档，并提供只读 API 和终端 IO 的独立回归检查。

## 验证命令

在仓库根目录执行以下命令；缓存初始化脚本仅为本机格式化器缓存目录异常提供兼容处理：

```powershell
$env:GRADLE_USER_HOME = "$PWD\.gradle"
$env:HTTP_PROXY = "http://127.0.0.1:1081"
$env:HTTPS_PROXY = "http://127.0.0.1:1081"
$env:GRADLE_OPTS = "-Dhttp.proxyHost=127.0.0.1 -Dhttp.proxyPort=1081 -Dhttps.proxyHost=127.0.0.1 -Dhttps.proxyPort=1081"
.\gradlew.bat -I tools/gradle/spotless-cache.init.gradle -I tools/terminal-io-check/verify.init.gradle build spotlessCheck verifyTerminalIo --no-configuration-cache
```

`build` 自带只读 API 回归，`verifyTerminalIo` 额外覆盖输出白名单、输入不筛选、配置迁移和数量守恒。回归使用独立内存仓库，不访问实际游戏存档；它不能代替游戏内客户端/服务端联调。

2026-10-02 提交前已执行上述命令：构建、Spotless、Checkstyle、只读 API 回归和终端 IO 的 79 项检查全部通过。正式 JAR 的 `mcmod.info` 版本为 `1.22.0`，包含 6 个 API 类，不含回归运行器。正式 JAR SHA-256：`FE0421B3A8A3ED1E5C16033A511B06E4D378AC586EA05EBC9444753948602079`。
