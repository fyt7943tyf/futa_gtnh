# futa_gtnh 1.23.2 改动与交付说明

日期：2026-10-04。版本来自 `version.txt`，发布分支 `main`。

## 新功能

共享 IO 节点方块（`futa_gtnh:io_node`）：共享背包存储的专用自动化输入输出口，把共享终端「主动搬运」那一块功能拆成独立方块，不带查看库存界面，也没有可被管道抽取的被动路径。

外观参考 EnderIO 导管：方块不占满整格，中心是一个 6×6×6 像素的小节点，仅向「那一面真的挨着能搬东西的方块」伸出连接臂与端帽；连接判定要求邻居在对准面上真的开出可访问槽位（ISidedInventory）或罐子信息（IFluidHandler），共享终端与其他 IO 节点不作为连接目标。连接在放置、邻居变化时重算，另有每 5 秒的低频兜底；重算只发生在 tick 内，不会在区块加载过程中触发相邻区块的同步加载。

右键某根连接臂打开该面的配置界面（点中心则打开第一个有连接的面，界面内 ←/→ 切面）。物品与流体各一组四态方向：关 / 抽入 / 输出 / 输入输出，默认全部关闭；端帽按模式着色（灰=关、绿=抽入、橙=输出、黄=双向），物品与流体同面时对半分。输出筛选与共享终端同一套（条目 + 矿辞预设 + 自定义前缀，空白名单禁止输出），条目列表默认按数量倒序、可切名称/模组；节奏沿用同一组档位。搬运完全复用 `TerminalIoEngine` 的守恒三段式逻辑。`TerminalIoConfig.Mode` 在枚举末尾追加 `PUSH_PULL`（ordinal 3），旧存档不受影响，共享终端界面仍为三态。

合成：末影珍珠×2 + 铁锭×4 + 漏斗×1。网络包新增 `PacketIoNodeSync`（S2C，#29）与 `PacketIoNodeConfig`（C2S，#30），上行要求开着节点界面、距方块 8 格内，速率吸附回档位。详见 `README-IO节点.md`。
