# 1.30.1：修复 AE 共享流体元件不可见

## 修复

- 修复同一 AE 网络同时安装共享背包物品元件与流体元件时，后登记的通道被错误去重、导致流体终端读不到共享流体的问题。现在每个网络的物品、流体通道分别选主元件；同通道的多个元件仍去重，不会重复计算存量。
- 修复拔出主元件后未触发重新扫描的问题，确保剩余同通道元件接管库存。

## 验证

- 新增双通道共存回归，在未修复的 1.30.0 代码上复现流体库存不可见，修复后通过。
- 覆盖两种登记顺序、流体存量读取与模拟提取、同通道去重、跨网络读取以及流体主元件拔出后的接管。
- `verifyAeCraftingDelivery`：117 项断言通过。
- 发布流程运行 `build spotlessCheck`，并核对 JAR 内版本、发布标签及附件校验值。
- 未启动游戏进行客户端/服务端实测。

## 兼容与升级

- 不修改存档格式、网络协议或配方；已有物品与流体元件继续使用。
- 客户端与服务端均更新至 1.30.1，并重启服务端以重新登记元件。
- 更新后在 AE 流体终端核对共享背包中的流体；本修复不改变普通物品终端的显示通道。
