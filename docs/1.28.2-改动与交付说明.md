# FutaGTNH 1.28.2

## 探矿仪中文矿名

- 修复 Detrav 电动探矿仪在中文客户端显示英文矿名的问题，包括 UHV 探矿仪 `gregtech:gt.detrav.metatool.01/106`。
- 服务端在生成探矿结果时直接写入简体中文名称，区分普通矿石与小型矿石，例如「铜矿石」「小型铜矿石」。
- 内置 1514 个 GTNH 2.9.0 中文材料译名，无需在服务端另外安装客户端汉化资源包。
- 服务端运行目录的 `GregTech_zh_CN.lang` 可覆盖或补充内置材料译名，修改后重启生效。未识别或未翻译的矿石保留原名。
- 译名缓存避免每个扫描方块重复解析材料；服务端启动时重新加载词典并清空缓存。

## 更新与兼容

- 本项修复只需更新服务端的 FutaGTNH，并重新扫描；单机集成服务端同样适用。
- 不需要修改 GregTech jar，本项修复不要求客户端同步更新。
- 探矿结果沿用 GT 原有数据包格式，保留对象编号、颜色、坐标及矿石图标所用的材料标识。
- 所有客户端收到统一的简体中文矿名，不改变 Minecraft 或 GregTech 的全局语言。
- 本次仅修复矿石名称，地下流体及其他界面文字保持现有行为。

## 验证

- `build`、`spotlessCheck` 均通过，产物已核对版本号、Mixin 注册和内置中文词典。
- `verifyProspectorChineseNames` 通过 LaunchWrapper 实际应用生产 Mixin，检查普通／小型矿石、重复矿石分组、GT 原数据包收发、颜色与坐标、材料标识、外部词典覆盖、缓存失效、未知材料回退及全局语言隔离。
- 完整构建还执行共享存储读 API、终端点击／搜索／书签取物、拆解机、库存上限及 IO 白名单等既有回归检查。
- 游戏中的探矿列表、悬停文字和地图筛选／高亮仍需实机复核。

详细说明见 [探矿仪服务端中文矿名](探矿仪服务端中文矿名.md)。
